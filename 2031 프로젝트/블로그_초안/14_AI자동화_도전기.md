# AI 블로그 자동화 도전기 — 세팅부터 지금까지

**카테고리**: ⑤ 투자일지 (부업 트랙, 상시 반복 포맷 1회차)
**연계**: AI 블로그 자동화 산업 이해하기
**상태**: 초안 — 실제 진행 상황 업데이트 필요

---

이 블로그 자체가 어떤 의미에서는 제 AI 자동화 도전의 첫 결과물입니다. 아직 "이렇게 해서 얼마를 벌었습니다"라고 자신 있게 말할 단계는 아니에요. 그래서 이번 글은 성공담이 아니라, 시작 단계를 있는 그대로 기록해두는 글로 남겨두려고 합니다.

## 왜 시작했나

부업으로 블로그, 인스타그램, 전자책, 쿠팡파트너스를 병행하고 있는데, 본업을 유지하면서 콘텐츠를 계속 만들어내려면 물리적인 시간의 한계가 명확했습니다. AI를 활용하면 콘텐츠 제작 속도를 끌어올릴 수 있겠다는 판단으로 시작하게 됐어요.

## 지금까지 한 것

- 블로그 주제·카테고리 기획 (금융생활정보, 금융동향, 산업분석, 종목분석, 투자일지, 자산현황 6개 카테고리)
- 애드센스 승인을 목표로 초기 콘텐츠 초안 작성
- 릴스 콘텐츠와 블로그 콘텐츠를 교차 활용할 수 있도록 소재 매칭

## 아직 정리가 안 된 것들

솔직하게 말씀드리면, 아직 특정 툴 하나에 정착하지도 못했고, 워크플로도 계속 바뀌는 중입니다. 이 부분은 어설프게 "이 툴 쓰세요"라고 추천하기보다, 실제로 몇 달 써보고 검증된 뒤에 업데이트하는 게 맞다고 생각해서 지금은 비워두려고 합니다.

## 이 시리즈를 통해 하려는 것

- [ ] 실제 사용 툴과 워크플로 공개 (검증 후)
- [ ] 콘텐츠 제작 시간이 얼마나 단축됐는지 기록
- [ ] 애드센스 승인 여부와 첫 수익 인증
- [ ] 시행착오와 실패담도 정직하게 공개

이 계정의 다른 글들과 마찬가지로, 여기서도 성공만 편집해서 보여드리진 않으려고 합니다. 다음 업데이트에서는 실제로 어떤 툴을 쓰고 있는지, 어디서 막혔는지부터 공유해볼게요.
